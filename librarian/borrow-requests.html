Request Review Guidelines

Consider the following points before approving or rejecting a borrowing request.

  • Check that the member has an active library account.
  • Confirm that the requested book is available according to the current inventory.
  • Review the member's current borrowing activities and applicable library borrowing limits.
  • Check whether the member has any restrictions that prevent additional borrowing.
  • Approve requests only when the relevant borrowing conditions have been satisfied.
  • Reject requests that do not satisfy the library's borrowing requirements.
  • Do not approve or reject a request that has already been processed.
  • Keep the decision and its related request information accurately recorded.

Borrowing Request Workflow

Understand what happens before a book is officially issued to a member.

  1. Member Submits a Request

    A registered member selects an available book and submits a borrowing request.

  2. Librarian Reviews the Request

    The librarian checks the member's account, borrowing eligibility, and book availability.

  3. Request Is Approved or Rejected

    The librarian records the decision. An approved request can proceed to the book issuing process.

  4. Approved Book Is Issued

    The librarian records the actual issue of the book through the active loans page.

    Go to Active Loans

  5. Book Is Returned

    The librarian records the returned book and updates its availability and loan status.

    Go to Returns
