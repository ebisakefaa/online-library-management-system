Return Processing Guidelines

Follow these guidelines when accepting and recording returned library books.

  • Verify the loan identifier before processing a return.
  • Confirm that the corresponding loan is still active.
  • Verify that the returned book matches the borrowing record.
  • Record the actual date on which the book is returned.
  • Update book availability only after the return operation succeeds.
  • Check the due date to determine whether an overdue fine may apply.
  • Calculate fines using the library's configured fine policy.
  • Retain completed borrowing and return records for the member's history.
  • Do not process the same loan as returned more than once.

Book Return Workflow

Understand what the system does when a member returns a borrowed book.

  1. Member Returns the Book

    The member brings the borrowed book back to the library.

  2. Librarian Verifies the Loan

    The librarian checks the loan identifier and confirms that the book belongs to the corresponding borrowing record.

  3. Return Is Recorded

    The system records the return date and updates the loan status to returned.

  4. Book Availability Is Updated

    The available quantity is increased after the return is successfully recorded.

  5. Applicable Fine Is Calculated

    When the book is overdue, the system calculates any applicable fine according to the configured library policy.
